# Ruralna Mehanizacija – landing page

Jednostavna, statička landing stranica za Ruralna Mehanizacija. Stranica naglašava originalne dijelove, gume i maziva, s izravnim CTA gumbima za poziv i WhatsApp.

## Kako pokrenuti
1. Kloniraj repo i otvori mapu.
2. Otvori `index.html` u pregledniku ili posluži sadržaj bilo kojim statičkim serverom (npr. `python -m http.server 8000`).

## Struktura
- `index.html` – sadržaj stranice i SEO meta tagovi.
- `styles.css` – mobilni-first dizajn s brend bojama, animacijama i mrežom sekcija.
- `script.js` – mikro animacije (paralaksa, karusel, ticker) i osnovni handler za formu.
